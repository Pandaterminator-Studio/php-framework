# Changelog

## Unreleased

- Added three runnable sample applications covering browser forms, a catalog API and queued sales reports.

- Added optional database-backed jobs, bounded CLI workers, delayed retries and failed-job recovery.

- Added nested object and list validation with field-level error paths.
- Added ordered query pagination with filtered totals and JSON page metadata.
- Added an in-process HTTP test client and a runnable test in generated applications.
- Scoped request injection to the active middleware or handler, including nested synchronous dispatches.

- Added an application kernel with native request/response objects and safe error handling.
- Added method-specific and named routing, groups, middleware and typed handler arguments.
- Added PSR-11 dependency injection, service providers and explicit environment configuration.
- Added reusable validation with structured errors and filtered validated data.
- Added lazy PDO connections, safe query building, nested transactions and migrations.
- Added an application generator and CLI commands for serving, routing and migrations.
- Added cache backends, atomic cache operations, PSR-3 logging, events and rate limiting.
- Added configurable authentication, authorization, CORS, session and request-ID middleware.
- Added request integrity challenges, strict input parsing and protected stateless routes.
- Added framework integration tests, Composer validation commands and PHP 8.3/8.4 CI configuration.
- Preserved legacy controller/router entry points while excluding old example sites and vendor copies from the library archive.

No public release or Packagist publication has been performed. Version compatibility and licensing must be decided before publishing a release.
